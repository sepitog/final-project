# ClarusMD File Index

This repository now functions as a documentation + implementation system. The files in this scaffold are designed to work together as a lightweight project control system for the ClarusMD MVP application.

## How to Use This Repository
Start with `index.html` as the main application entry point for the current UI. Use [PLAN.md](./PLAN.md) to understand the product direction and system structure, [AGENTS.md](./AGENTS.md) to understand the development rules, [TODO.md](./TODO.md) to track active work, [LOGBOOK.md](./LOGBOOK.md) to review project history, and [UNIT-TESTS.md](./UNIT-TESTS.md) to understand MVP quality expectations.

## Core System Files
- `index.html` serves as the main ClarusMD application entry point and current landing page UI.
- `AGENTS.md` defines the ClarusMD development agent protocol and documentation enforcement rules.
- `PLAN.md` provides the strategic system overview, active MVP architecture, and phased roadmap.
- `FILE-INDEX.md` explains how the project documentation is organized and how the files relate.
- `TODO.md` tracks project status, priorities, and current implementation tasks.
- `LOGBOOK.md` records dated actions, reasoning, and project observations.

## Supporting / Future Files
- `UNIT-TESTS.md` outlines the MVP testing strategy for validation, logic, and output correctness.
- Additional documentation may be added later for implementation notes, data references, or system decisions as the project grows.

## Repository Note
At this stage, ClarusMD contains active project documentation alongside the early MVP application scaffold. Future structural additions should remain consistent with the system described in [PLAN.md](./PLAN.md).
